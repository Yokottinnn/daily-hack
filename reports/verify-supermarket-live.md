## 4. 読み方

| 出方 | 意味 |
| --- | --- |
| `verdict: 在る` が 2 本 | **出ている。** 利用者の画面の問題（キャッシュ等） |
| `gone: true` | **消えている。** 誰が消したかを次に調べる |
| `開けなかった` ＋ CDP が NG | **判定できていない。** Chrome を直してから測り直す |
| タイムラインに並んでいない | 個別 URL が出ても届いていない。X 側の制限を疑う |

**どれであっても「たぶん出ています」とは言わない**（最上位ルール 11）。
