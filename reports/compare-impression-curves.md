## 4. 読み方

| 出方 | 意味 |
| --- | --- |
| 同じ ~3h で過去も 40〜60 | **異常ではない。** いつもこの程度 |
| 過去は ~3h で数百 | **今回だけ絞られている。** 再投稿が効いた疑いが濃い |
| 記録が 2〜3 本しか無い | **まだ比べられない。** 数日 溜めてから判断する |

**「たぶん X に絞られている」とは、数字が揃うまで言わない**（最上位ルール 11）。

### 時間帯の話は、これだけでは出せない

出した時刻は **00:26 と 18:23 の 2 点**しか無い。
**2 点で「夕方が弱い」とは言えない。** 時間帯を言うには、
同じ内容を違う時刻に出した記録が要る。
