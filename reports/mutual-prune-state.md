## 3. `reply-followers.json` 側は古くなっていないか

フォロー系ジョブは **`reply-followers.json` を見て「既にフォロー済み」を判定する。**
**mutual-prune が外したのにそちらが古いままだと、判定がずれる。**

```
  mutual-prune が外した相手のうち
    reply-followers.json にも居る: 2 件
      → そちらも外れている扱い  : 0 件
      → **まだフォロー中の扱い** : 2 件
    reply-followers.json に無い  : 4 件（別経路でフォローした相手）

  → **ずれている。** 次の洗い替え（x61 系）で直るはずだが、
     それまでは「フォロー中」と誤認する
```

## 4. 次はいつ走るか

```
  StartInterval=43200 秒（12 時間）/ RunAtLoad=false
  ログの最終更新: 2026-09-14 05:10
```

**12 時間 間隔なので、1 日 最大 2 回 × 8 件 = 16 件 が上限。**
上限は安全弁であって予想ではない（実績は 2026-09-13 に 6 件）。
