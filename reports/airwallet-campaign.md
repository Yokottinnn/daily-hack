リポジトリの `src/data/referrals.ts` にある `air-wallet` の URL。
**コードそのものはここに出さない**（公開リポジトリに載るため）。

```
  HTTP/redirect: 302 https://apps.apple.com/app/id1549123889?mt=8
```

## 3. この後やること

上の (1)〜(3) で **期間の終了日と特典額が一意に決まったら**、
その数字だけを使って X 投稿の草案を書く。**割れていたら書かない。**

判定できなかった場合は、アプリの `設定/アカウント → 友だち招待` 画面が
**一次情報として最も確実**（表示されている額と期限がそのまま今の条件）。
