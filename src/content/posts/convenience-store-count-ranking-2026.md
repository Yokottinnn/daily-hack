「コンビニがいちばん多い都道府県はどこ？」「うちの県はセブンとローソン、どっちが多いの？」——3社とも公式サイトに都道府県別の店舗数を出しているけれど、1つの表に並べたものは見当たらない。

だからアタシが並べた。土台は**セブン‐イレブン・ファミリーマート・ローソンの公式サイトの都道府県別店舗数<strong>。3社とも公式の数字をそのまま足したうえで、</strong>総務省の人口推計で割った「人口1万人あたりの店舗数」**、**どのチェーンが何割を占めるか**、**セブン‐イレブンの50年の店舗数の推移**まで足して、都道府県を1つずつ見ていくわ。

<div class="hakkako-says">
  <div class="hakkako-quote">先に一番の驚きを言っとく。<strong>セブンがいちばん多い都道府県は26</strong>。でも<strong>大阪と愛知はファミマ</strong>、<strong>青森・四国・山陰はローソン</strong>が1位。それと、<strong>店の数がいちばん少ない鳥取は、人口1万人あたりだと全国3位</strong>。数だけ見てると、まるで逆の結論になるのよ。</div>

## セブン‐イレブンの店舗数の推移｜1974年の15店から2万1,743店

セブン‐イレブン・ジャパンは公式サイトで、1974年度からの店舗数と売上高（チェーン全店）の推移を出している。

| 年度 | 店舗数 | 売上高（チェーン全店） |
| --- | --- | --- |
| 1974年度（昭和49年度） | **15店** | 7億円 |
| 1980年度（昭和55年度） | 1,040店 | 1,536億円 |
| 1990年度（平成2年度） | 4,270店 | 9,319億円 |
| 2000年度（平成12年度） | 8,602店 | 2兆466億円 |
| 2010年度（平成22年度） | 13,232店 | 2兆9,476億円 |
| 2020年度（令和2年度） | 21,167店 | 4兆8,706億円 |
| 2024年度（令和6年度） | **21,743店** | **5兆3,698億円** |

<p class="source-note">出典：<a href="https://www.sej.co.jp/company/suii.html" target="_blank" rel="noopener">セブン‐イレブン・ジャパン「売上高、店舗数推移」</a>。各年度の数字をそのまま抜き出した。</p>

1974年度の15店から、50年で約1,450倍になった。1万店を超えたのは2003年度（平成15年度・1万303店）、2万店を超えたのは2017年度（平成29年度・2万260店）。そこからの伸びはゆるやかで、2020年度から2024年度の4年間で増えたのは576店。売上高は2020年度に前の年（5兆102億円）より下がったあと、2024年度は5兆3,698億円まで戻って、表の中でいちばん大きい。

10年ごとに店の増え方を見ると、1980年代（1980→1990年度）は約3,230店、1990年代は約4,330店、2000年代は約4,630店、2010年代（2010→2020年度）は約7,940店増えた。いちばん多く増えたのは2010年代で、とくに2012年度から2015年度は、毎年1,000店以上ずつ増えている。1店あたりの年間の売上（売上高÷店舗数）は、2024年度で約2億4,700万円。1990年度の約2億1,800万円より大きくなっているわ。

店の数が2万を超えてからは、店を増やすより1店あたりの売上を上げる段階に入っている、と読めるわね（アタシの読み）。2026年10月末の国内店舗数は2万1,956店で、2024年度末より少し増えている。

## 全国のコンビニの10年｜店は2.8%増、売上は14%増

日本フランチャイズチェーン協会（JFA）は、正会員のコンビニの会社の数字をまとめた「コンビニエンスストア統計調査」を毎年出している。2016年と2025年を並べると、こうなる。

| | 2016年 | 2025年 | 10年の変化 |
| --- | --- | --- | --- |
| 店舗数（12月末） | 54,501店 | **56,054店** | +2.8% |
| 年間売上高（全店） | 10兆5,722億円 | **12兆583億円** | +14.1% |
| 年間来店客数（全店） | 172億785万人 | **163億4,142万人** | −5.0% |
| 平均客単価（全店） | 614.4円 | **737.9円** | +20.1% |
| 対象の会社 | 正会員9社（9月から8社） | 正会員7社 | |

<p class="source-note">出典：<a href="https://www.jfa-fc.or.jp/particle/320.html" target="_blank" rel="noopener">日本フランチャイズチェーン協会「コンビニエンスストア統計調査」</a>の2016年と2025年の年間集計。10年の変化はアタシの計算。対象の会社の数が年によってちがうので、増減は目安。</p>

10年で、店の数はほとんど増えていない（+2.8%）のに、売上は14.1%増えた。来る人は5.0%減ったけれど、1回の買い物の金額（客単価）が614円から738円へ、20%上がっている。JFAの2025年の集計は、高付加価値の商品やクーポンなどの販促で客単価が伸び、訪日外国人や大阪・関西万博も売上に効いたと書いている。来店客数は4年ぶりに前の年を下回ったわ。

2025年のJFAの店舗数（56,054店）と、この記事の3社合計（53,134店・2026年の数字）を比べると、3社でコンビニ全体の約95%を占める計算になる（対象の会社と時点がちがうので目安）。
