# Daily Hack ads.txt
#
# ■ 重要: このサイトはサブドメイン（daily-hack.fieldbeside.com）で動いている
#
#   ads.txt のクロールは **ルートドメインから始まる**。サブドメインの ads.txt は、
#   ルートドメインの ads.txt から SUBDOMAIN= で参照されている場合にだけ
#   クロール・適用される。参照が無ければサブドメイン側は無視され、
#   ルートドメイン（fieldbeside.com）の ads.txt にフォールバックする。
#   https://support.google.com/adsense/answer/9785052
#
#   → **fieldbeside.com/ads.txt に次の 1 行が要る**（このリポジトリの外）。
#        SUBDOMAIN=daily-hack.fieldbeside.com
#      それが置けないなら、広告事業者の行は fieldbeside.com/ads.txt 側に書く。
#
#   HTTP と HTTPS の両方でアクセスできることも確認すること。
#
