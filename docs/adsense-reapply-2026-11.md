# AdSense「有用性の低いコンテンツ」で不承認（2026-11-12）の対策と切り戻し

> 利用者「Google Adsenseが許可されなかったので対策してほしい／対策したとしても許可されない可能性もあるから、その場合切り戻しができるようにして」。
> 担当: affiliate（AdSense の申請は blog3 が 10/31 に fieldbeside.com で出した）。作戦室の分析レポート `2026-11-12-adsense-low-value`。

## 不承認の理由（Google の通知）
「有用性の低いコンテンツ」。独自の価値・ウェブ上での一貫したプレゼンス・ユーザーの関心が足りない、とされた。
公式の目安（https://support.google.com/adsense/answer/10015918）: 十分な量の独自コンテンツ、ほとんど中身のないページを避ける、メニューで整理する、同じ内容を複数ページに載せない。

## 原因と見たもの（2026-11-12 に確かめた事実）
1. **審査を出した fieldbeside.com が 1 ページの会社サイトで、Daily Hack へのリンクが 0 本**（10/31 の調べで指摘したまま）。審査はこのドメインを見る
2. **ブログのサイトマップ 961 件のうち 774 件がタグのページ**で、620 個は記事 1 本だけ（ほとんど中身のないページ）。下書き一覧・サイト内検索もサイトマップに載っていた
3. 成果リンクのある記事は 158 本中 109 本（69%）。利用者の判断で**そのまま**（収益の柱）

## やったこと
| どこ | 変更 | PR |
| --- | --- | --- |
| fieldbeside.com | 「MEDIA / 運営メディア」欄（Daily Hack の説明・カテゴリ・メディアについて・読まれている記事 6 本）、ヘッダーとフッターのリンク、`ads.txt` に `subdomain=daily-hack.fieldbeside.com` | fieldbeside-website #3 |
| ブログ | 記事 2 本以下のタグのページを noindex にしてサイトマップから外す（湾岸の地区・湾岸ニュースは 1 本以上で残す）。下書き一覧・サイト内検索もサイトマップから外す。**サイトマップ 961 → 258 件**（タグ 774 → 73） | この PR |

## 再申請の手順
1. 2 つの PR がマージされ、本番に出たのを確かめる（fieldbeside.com に MEDIA 欄・ads.txt に subdomain の行）
2. Search Console でサイトマップを送り直す（Mac の ops/tasks で行う）
3. **1〜2 週間おいて**（Google が新しいサイトマップと noindex を読むまで）、利用者が AdSense の［サイト］で「審査をリクエスト」
4. 結果は作戦室の分析レポートと決定ログに書く

## 切り戻し（不承認のままだったとき・戻したいとき）
- **ブログ**: `src/data/site-quality.json` の `tagIndexMinPosts` を `0`、`sitemapExclude` を `[]` にする（2026-11-12 にこの設定でビルドし、サイトマップが元の 961 件に戻ることを確かめた）。またはこの PR のマージコミットを revert
- **fieldbeside.com**: 変更前の状態はブランチ `rollback/before-adsense-2026-11-12`（3d8cd5e）。fieldbeside-website #3 のマージコミットを revert する
