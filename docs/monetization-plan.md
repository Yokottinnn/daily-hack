# ブログ収益化の勝ち筋

調査日: 2026-09-06

## 結論を先に

1. **クリック報酬型は、このブログでは伸びない。** AdSense より上は存在しない。
2. **本命は成果報酬。** 記事の構成が金融・通信の比較メディアそのもので、単価が 2 桁ちがう。
3. **ただし、いま最優先で直すべきは「PV が測れていない」こと。** 効果を測れないまま
   広告を足しても、何が効いたか分からない。

## 0. 前提｜いまの数字

**実測**（2026-08-31 の週次レポート・GSC 直の値）。

| 指標 | 値 |
| --- | --- |
| Google 検索 表示（直近28日） | 628 |
| Google 検索 クリック（直近28日） | **32** |
| CTR / 平均掲載順位 | 5.1% / 9.1位 |
| 90日累計 | クリック 42 / 表示 840 |
| 記事本数 | 72 |
| Cloudflare の PV | **不明** |

**Cloudflare の PV が不明なのは、週次レポートが壊れているから。**
2026-08-31 の Slack レポートには `${ALL_VISITS}` が**展開されないまま**載っている。

```text
• CF visits（全パス）: *${ALL_VISITS}* / requests ${ALL_REQ}
```

**検索からの訪問が月 32。** ここを直視しないと、どの広告を入れても話が始まらない。
クリック単価 1〜3 円の広告では**月あたり数円〜数十円**にしかならない。

## 1. クリック報酬型を洗った結果

| サービス | 状態 | 単価の目安 | このブログでの評価 |
| --- | --- | --- | --- |
| **Google AdSense** | **未審査** | 1クリック数十円 | クリック型ではこれが天井。通すのが唯一意味のある一手 |
| **忍者AdMAX** | **稼働中**（4枠） | **1クリック 1〜3 円** | 審査なしで入る保険。これ単体で収益にはならない |
| **nend** | **2024-03-29 サービス終了** | — | **いまだに「アドセンス以外おすすめ」記事に載っているが死んでいる** |
| **i-mobile** | 現存 | 忍者と同水準 | AdSense が通らないジャンル向けの代替。併用はできる |
| popIn Discovery / Logly Lift / Taboola / Outbrain | 現存 | — | **媒体規模が前提**。月間数億〜1,200億 imp のネットワークで、個人ブログ規模は導入対象外 |

**クリック報酬型で AdSense を超えるものは無い。** 忍者AdMAX と i-mobile は
「AdSense が使えない場合の代替」であって、上位互換ではない。

### 忍者AdMAX が今どれだけ稼いでいるかは、そもそも測れていない

`ads.txt` に忍者の行が 1 行も無く、しかもサブドメイン運用のため
ルートドメインからの参照も無い（[`ad-slots.md`](./ad-slots.md)）。
**入札が減る条件が揃っている。**

## 2. 本命は成果報酬｜記事の中身がそれを要求している

記事 72 本の内訳を見ると、**金融・通信の比較メディア**そのもの。

| ジャンル | 本数（主なもの） |
| --- | --- |
| 金融 | クレカ 4／ネット銀行／NISA 2／iDeCo／FX／カードローン／自動車保険／住宅ローン借り換え／高額療養費 |
| 通信 | 格安SIM 2／ネット回線 |
| 光熱 | 電気ガス 2／節電 |
| ふるさと納税 | 4 |
| ポイ活 | 8 以上 |
| 湾岸ライフ・おでかけ | 15 前後 |

**`category: comparisons` が 25 本。** 比較記事は成果報酬がいちばん効く型。

単価の目安。

| 案件 | 1 件あたり |
| --- | --- |
| クレジットカード発行 | **5,000〜20,000 円** |
| 金融全般（カードローン・証券口座など） | 2,000〜50,000 円（案件差が大きい。SBI証券は 300 円という報告もある） |
| 忍者AdMAX | 1 クリック **1〜3 円** |

**クレカ 1 件 ＝ 忍者AdMAX の 2,000〜20,000 クリック分。** 桁が違う。

## 4. 記事を 1 行も書き換えずに効く 2 つ

**72 本ある資産に対して、これがいちばん費用対効果が高い。**

### ① バリューコマース LinkSwitch

JS タグを 1 回入れるだけ。既存記事の中にある「楽天市場へのリンク」「Yahoo!ショッピングへの
リンク」「ふるさと納税サイトへのリンク」が**自動でアフィリエイトリンクになる**。

- 過去記事も含めて一括で変換される
- 未提携の広告主とは自動で提携する機能がある
- **`BaseLayout.astro` にタグを 1 つ足すだけ**で全ページに効く

### ② もしも かんたんリンク

Amazon・楽天・Yahoo!ショッピングを 1 枚のカードにまとめる部品。
商品を挙げている記事（ふるさと納税・値上げ対策・ヨドバシ）に効く。

## 6. 落とし穴

- **ふるさと納税は 2024-10-01 から、返礼品を強調した宣伝広告が禁止**になっている。
  ふるさと納税の記事 4 本は書き方に制約がかかる
- **金融は YMYL**。E-E-A-T が弱いと検索順位が伸びない。運営者情報・執筆者情報が効く
- **AdSense と他社ネットワークの併用は規約上 OK**。効く制約は
  「AdSense を模した広告は不可」と「広告よりコンテンツが多いこと」（[`ad-slots.md`](./ad-slots.md)）
- **セルフバックは収益ではなく一時金。** 継続的な収益と混ぜて数えない
