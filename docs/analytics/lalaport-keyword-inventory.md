## なぜ棚卸しが要るか

記事単位の平均順位（8/17 時点で 7.6 位・表示 261）は、**その記事が出た全クエリの順位を
表示回数で加重平均した値**。1 位で出ている語と 40 位で出ている語が混ざるため、
この数字からは打ち手が決まらない。

実測が届いたとき即座に判断できるよう、先に「狙い」の側を固定しておく。

### 読み取れたこと

1. **#1「売上ランキング」だけで 112／124 表示。** この記事は実質「ららぽーと 売上ランキング」の記事として認識されている。
   にもかかわらず、**タイトルに「ランキング」が入っていなかった**（`ららぽーと完全ガイド 2026｜…`）。
   H2 にはあるが、タイトルに完全一致が無いのは取りこぼしになる。**2026-08-29 にタイトルを
   `ららぽーと売上ランキング 2026｜…` に変えた。**
2. **順位は 6.4〜7.8 位で、1 ページ目の下に張り付いている。** 表示は前回（338）から 413 へ +22% 伸びたのに、
   **クリックは 23 のまま横ばい**で CTR が 6.8% → 5.6% に落ちた。**順位が上がらない限りクリックは増えない位置。**
3. **#5「店舗数ランキング」は 10.2 位。** #189 で H2 化した効果で認識はされているが、1 ページ目の境界。
4. **#4「大きさ」は判断できない。** 「大きい順」7.0 位・「どこが大きい」9.0 位と、
   「大きさ ランキング」49〜50 位・「大きい」65 位が同居している。**どれも表示 1 回**で、
   この順位はサンプルとして小さすぎる。**次回の実測まで結論を出さない。**
5. **✗ だった #3（何店舗）と #13（セール いつ）は、実測でも 1 件も返っていない。**
   受け皿が本文だけだと、やはり拾えない。**2026-08-29 に「よくある質問」の H2 を足して、
   疑問形の受け皿を作った**（何店舗／一番売上が高い／一番大きい／店舗数が多い／セールはいつ／駐車場は何時間無料）。

## 実測が届いたときの読み方

| 実測の出方 | 意味 | 打ち手 |
| --- | --- | --- |
| ✅ の語が上位に出ている | 見出しが効いている | 触らない |
| ✗ / △ の語が**出ていない** | 受け皿が本文だけで拾えていない | 見出しを検索語に寄せる |
| ✗ / △ の語が**低順位で出ている** | 認識はされているが弱い | 見出し化＋内部リンク集約 |
| 表に無い語が上位に出ている | 想定外の当たり。**ここがいちばん価値がある** | その語を軸に節を厚くする |

**語が 1 つも返らない場合は「取れていない」と読まないこと。** 表示回数の少ない語は
GSC が匿名化して返さない（`docs/seo-monitoring.md` 参照）。
