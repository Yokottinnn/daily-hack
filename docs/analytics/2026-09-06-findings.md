## 補足｜Cloudflare が取れない理由

旧レポートは **GitHub Actions の `weekly-pv-report` を dispatch して、その実行ログを
文字列で拾う**という作りだった。CF のトークンが GHA の Secret にしか無いため。

```python
subprocess.run(["gh", "workflow", "run", "weekly-pv-report.yml", ...])
time.sleep(22)
rid = ... gh run list --limit 1 ...      # ← 22 秒で新しい run が出ている保証は無い
log = ... gh run view $rid --log ...     # ← ここから STDOUT_TOTALS を文字列で拾う
```

**この経路が壊れて `${ALL_VISITS}` という文字列を拾っていた。**
新しいレポートは Cloudflare の API を直接叩くので、この橋そのものが要らない。
**必要なのは Mac 側に API トークンを 1 つ置くことだけ。**
