# X 告知の草案はここに残す

**2026-09-20 に「1 投稿目の文章が全然違う、なんで勝手に変えてんの」と指摘された。**

原因ははっきりしている。**画像はリポジトリに残していたのに、文面はチャットにしか
出していなかった。** セッションの記録が切り替わった時点で、承認済みの文面が
どこからも読めなくなり、**書き直してしまった。**

CLAUDE.md 最上位ルール 3「会話の中だけに状況を残さない」を、文面で踏んだ形になる。

## 決まり

**草案を出したら、同じターンでここに `<slug>.md` を置いてコミットする。**
チャットに出すのは変わらないが、**チャットだけにしない。**

```text
docs/x-drafts/<slug>.md
```

書式は次のとおり。**本文は加工せずそのまま置く。** 要約も整形もしない。

```markdown
# <記事タイトル>

- 記事: <URL>
- 画像: public/images/<slug>/x/*.jpg（4 枚）
- 状態: 草案 / 承認済み（YYYY-MM-DD） / 投稿済み（tweet_id）

## [1/2]（重み NNN）

​```
（本文そのまま）
​```

## [2/2]（重み NNN）

​```
（本文そのまま）
​```
```

- **承認をもらったら、状態の行を書き換えてコミットする。** 承認そのものが記録になる
- **投稿できたら `x_tweet_id` を書き足す**（一次情報・最上位ルール 11）
- **文面を直したら、前の版を消さずに下に積む。** どう変わったかが後から見える
