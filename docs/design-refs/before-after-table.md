## 何が「整理されている」のか（6 点）

| # | 要素 | 効いている理由 |
| --- | --- | --- |
| ① | **最上段の黒帯に 1 行のフック** | 「実は、〜」で**読む人自身の損**を先に突きつける。白黒反転なので最初に目が行く |
| ② | **左半分に主張 1 文。要の 2 語だけ色箱で白抜き** | 「昇給」「税金対策」だけが目に残る。比べる 2 つを**同じ色箱**に入れて対にしている |
| ③ | **右半分に Before → After の表。行は 3 つ** | **列ごとに色を変える**（Before 青・After ピンク）。間に **→**。**差額の列だけ太枠＋橙で浮かせる**＝答えの列 |
| ④ | **表の下に前提を小さく** | 「40歳未満単身・〜の場合。金額は一例」。数字の信用を取りつつ、主張の邪魔をしない |
| ⑤ | **キャラが表の右上の角に重なって覗き込む** | 表とキャラが 1 つの塊に見え、無機質な表に視線を引き込む |
| ⑥ | **左下に行動の 1 ボタン** | 「参加無料」の丸バッジを角に重ねる |

**左＝主張（言葉）、右＝証拠（数字）。** 視線は ①上 → ②左 → ③右 → ③の差額列 で止まる。
**差額列が答え**で、そこに一番強い色を置いている。

## このアカウントで使うときの置き換え

**キャラ設定は変えない**（一人称「アタシ」・語尾「〜わよ／〜のよ／〜なさい」・二人称「あんた」）。

| 元 | こちら |
| --- | --- |
| ① 「実は、あなたのお給料、こんなに引かれています。」 | **ハッカー子の言葉で。** 例「あんた、毎年これだけ損してるのよ。」 |
| ② 要の語を色箱 | ブログの配色トークン（`--pink` など。`src/styles/global.css` の `:root`）だけを使う。**紺は使わない** |
| ③ Before / After / 差額 | **記事に在る数字だけ。** 3 行。差額列を一番強い色に |
| ④ 前提の注記 | **記事の前提をそのまま**（例「1日1万歩・365日・公表条件から計算」）。**出所の行ではない**ので X 画像に置いてよい（最上位ルール 8 は出所の行を禁じているが、前提は別物） |
| ⑤ 女性のイラスト | **ハッカー子の透過 PNG**（`public/images/expr-*.png`。得意げなら `expr-05-smug`、驚きなら `expr-07-gasp`） |
| ⑥ 申込ボタン | **X 画像には置かない**（押せないボタンは嘘になる）。記事では本文の CTA に任せる |
