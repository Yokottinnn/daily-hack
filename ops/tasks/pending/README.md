# `ops/tasks/pending/` — **まだ走らせたくないタスク**

## ここは実行されない

`scripts/ops-run-tasks.sh` はこう列挙している。

```bash
for t in $(git ls-tree --name-only "origin/main:ops/tasks"); do
  case "$t" in *.sh) ;; *) continue ;; esac
```

**`ls-tree` は再帰しない。** このディレクトリは `pending` という 1 エントリとして
出るだけで、**`.sh` で終わらないので飛ばされる。** 中のファイルは走らない。

## 何のために在るか

**出す時刻が決まっているタスクを、Git に残したまま待たせる。**

`ops/tasks/` に置いた瞬間、**1 分後にはポーラーが実行する。** 止める方法は無い
（`done/` はタスクが終わってから書かれるので、先に印を置くこともできない）。

かといってセッションのスクラッチパッドに置くと、**実行環境が消えたら一緒に消える**
（CLAUDE.md 最上位ルール 3）。**会話の中だけに状況を残さない。**

## 使い方

**時刻が来たら 1 段 上げるだけ。**

```bash
git mv ops/tasks/pending/x112-post-tokyo-supermarket.sh ops/tasks/
# → コミットして PR → **同じターンでマージまで見届ける**（最上位ルール 12）
```

マージした時点から **1 分以内**に Mac が実行する。

## 置くときの約束

- **ファイル名は最終形にする。** 上げるときに名前を変えない
  （`done/` の印はファイル名で付くため、途中で変えると二重実行しうる）
- **なぜ待たせているのかを、ファイルの先頭コメントに書く。**
  次のセッションが「なぜここに在るのか」を読めるようにする
- **上げ忘れを防ぐ。** `docs/session-handoff.md` の「次にやること」に必ず書く
